# 导师汇报版（10页）

按“问题—解决方案—解决过程—结果”重新组织原16页汇报，增加每页信息量。
保留原版，不覆盖正在打开或已修改的旧PPT。

## 直接使用

- `知识图谱问答_导师汇报版_10页_2026-11-09.pptx`：正式汇报文件，16:9，含逐页讲稿备注。
- 同名PDF：发送、预览与备用展示。
- `逐页讲稿.md`：约15分钟讲述参考。
- `预览-1.png`至`预览-3.png`：页面总览。

## 表现形式和验证边界

沿用本地确定性蓝白排版；当前未配置图片生成API，也无原生生图工具，未调用外部生图服务。
PPT每页是1920×1080整页图片，**正文不是可逐字编辑的文本框**，备注为可编辑文字。
这与原版一致，避免中文字体跨设备替换。修改正文请编辑`slides_plan.md`并重建。
页脚来源编号对应`证据索引.json`，包含仓库相对路径与SHA-256。
没有新增实验、修改评分器或改变标答；下一步均标注为计划。

重建：

```bash
uv run --offline --no-project --with python-pptx --with pillow --with pymupdf python 汇报/2026-11-09/导师汇报版/build_deck.py
```

脚本检查文字区域、PPT页数/比例/备注/嵌图、PDF原始像素；重建后必须重新目视检查。
本版不是PowerPoint/Keynote回渲染验证；结构校验与视觉验收记录见`排版检查.json`。
